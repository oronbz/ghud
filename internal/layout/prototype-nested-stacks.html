Nested stacks: does arranging feel right?

Issue #58 proposes that a cell in a row can hold its own rows (a stack), so one Widget can be full height on one side while others stack beside it. This spike simulates visor's grid using the proposed rules, so you can try them with the mouse and visor's own keys. It checks three things. First, drops are local to the tile: dropping on a Widget's top or bottom edge stacks with it, and dropping over a row seam or the dashboard edge opens a full-width row. Second, keyboard move and resize act on the nearest container. Third, arrow focus follows the tiles' positions.


        

      

      
Drag a title to move a Widget · drag a border between Widgets to resize · click a Widget to focus it.
        Keys (click the grid first): ←→ and ⇧←↓↑→ focus, Tab next top-level row, m arrange; in arrange mode ←↓↑→ move, ⇧←↓↑→ resize, ⏎ keep, esc revert.
